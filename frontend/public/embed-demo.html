AstroRemedis Chat Embed Demo

Click the round bubble at the bottom to open the embedded chat. Fixed size works on both mobile and web!

How to embed

Add the following code to your website. Same size works for both mobile and web:

<script src="https://YOUR_DOMAIN/embed-sdk.js" async></script>
<script>
  window.AstroRemedisChat.init({
    iframeUrl: 'https://YOUR_DOMAIN',
    width: 340,
    height: 600
  });
</script>

Note: This size (340x600) works well on both mobile devices and desktop screens.
